Smart Monitoring Tandon Air (Ultrasonik & ESP8266)

Perancangan sistem cerdas untuk memantau kapasitas volume air pada tandon rumah secara real-time. Sistem ini menggunakan sensor ultrasonik untuk membaca jarak permukaan air, yang datanya kemudian diproses secara nirkabel oleh mikrokontroler NodeMCU ESP8266.

Agar lebih praktis, sistem ini saya integrasikan dengan antarmuka Blynk. Sebagai fitur pengaman tambahan (fail-safe), saya memprogram logika peringatan menggunakan bot Telegram. Ketika volume air menyentuh batas minimum kritis, sistem akan otomatis mengirimkan pesan notifikasi ke Telegram sehingga pemantauan di rumah bisa dilakukan dengan mudah, dan pompa dapat dinyalakan tepat waktu.

  • Komponen Inti: NodeMCU ESP8266, Sensor Jarak Ultrasonik (HC-SR04 / JSN-SR04T).
  • Platform & Komunikasi: Aplikasi Blynk (Dashboard) & API Telegram Bot.

Logika Utama (Notifikasi Telegram & Blynk):

// Fungsi membaca jarak ultrasonik dan mengirim peringatan
void cekTandon() {
  // Membaca jarak dari sensor
  digitalWrite(TRIGGER_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIGGER_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIGGER_PIN, LOW);
  
  long duration = pulseIn(ECHO_PIN, HIGH);
  float distance = (duration * 0.034) / 2;
  
  // Mengirim data ke aplikasi Blynk (misal di Virtual Pin V1)
  Blynk.virtualWrite(V1, distance);
  
  // Logika Notifikasi Telegram jika air hampir habis (jarak > 80cm)
  if (distance > 80.0 && !pesanTerkirim) {
    String pesan = "⚠️ Peringatan: Air di tandon hampir habis! Jarak: " + String(distance) + " cm. Segera nyalakan pompa.";
    bot.sendMessage(CHAT_ID, pesan, "");
    pesanTerkirim = true; // Flag agar tidak spam pesan berulang
  } else if (distance < 50.0) {
    pesanTerkirim = false; // Reset status saat air sudah kembali terisi
  }
}
